🔮 Cara Melakukan Prediksi

Langkah 1: Pilih halaman "🔮 Prediksi" dari sidebar
Langkah 2: Isi form dengan data mahasiswa:
  • 👤 Jenis Kelamin: Laki-laki atau Perempuan
  • 🏫 Asal SMA: SMA atau SMK
  • 💍 Status Pernikahan: Belum atau Sudah
  • 📚 Ukuran Program: Reguler atau Ekstensi
Langkah 3: Klik tombol 🚀 Lakukan Prediksi
Langkah 4: Lihat hasil prediksi:
  • ✅ Status: Tepat (Lulus tepat waktu)
  • ⏰ Status: Terlambat (Terlambat Lulus)
  • 📊 Confidence: Tingkat kepercayaan prediksi dalam %
  • 🎯 Probability: Probabilitas untuk setiap kelas

❓ Troubleshooting

Problem: "streamlit command not found"

Solution: Install streamlit menggunakan

pip install streamlit

Problem: "Port 8501 already in use"

Solution: Gunakan port berbeda:

streamlit run app.py --server.port 8502

Problem: File model tidak ditemukan

Solution: Pastikan sudah menjalankan model.py terlebih dahulu untuk membuat file model

python model.py

Problem: Aplikasi loading lama

Solution: Tunggu 10-15 detik untuk loading awal, atau restart aplikasi
